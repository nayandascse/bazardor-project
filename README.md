# বাজার দর (BazarDor)

A responsive Bengali market-price explorer for everyday essentials in Bangladesh. Browse product prices, compare market estimates, explore categories, and sign in to access protected product details.

## Technologies

- Next.js App Router
- React 
- Tailwind CSS v4
- Better Auth — email/password and Google
- react-hot-toast
- Lucide React — icons

## Key features

1. Price-riser and price-faller sections plus product cards with Bengali-formatted numbers.
2. Category routes with numeric low-to-high/high-to-low sorting.
3. Protected product details with minimum, maximum, average, and market-by-market prices.
4. Better Auth email/password registration and sign-in, with Google
5. Profile view and profile-name update using Better Auth's
